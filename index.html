01 / Overview

The project

Triathlon training involves balancing three sports, personal schedules, and recovery. This project explores a software-based approach to generating structured training plans and adjusting them when circumstances change.

Current status: In development. Features below describe the project goals, not completed or validated capabilities.
02 / Design goals

Planned features

Planned feature 01

Athlete profile

Represent an athlete's experience, goals, and available time.

Planned feature 02

Weekly scheduling

Organize swim, bike, and run sessions around weekly commitments.

Planned feature 03

Adaptive planning

Explore transparent rules for adjusting a schedule when sessions are missed.

Planned feature 04

Automated testing

Test scheduling constraints, invalid inputs, and plan-generation rules.

Testing and validation

04 / Development

Project roadmap

  1. Define requirements and training data models.
  2. Build the core plan-generation logic.
  3. Write and run automated tests.
  4. Develop the web interface.
  5. Implement and evaluate adaptation rules.
  6. Document the results and known limitations.
