# adaptive-triathlon-planner
A C# web application designed to help triathletes generate and adapt training plans for a 70.3 triathlon based on their availability, experience, training goals, and recovery needs.

## Project Goals

- Generate structured weekly swim, bike, and run training plans.
- Account for an athlete's weekly availability and training experience.
- Explore rules for adjusting training when sessions are missed or recovery needs change.
- Apply software engineering principles through modular C# code and automated tests.

## Planned Features

- [ ] Athlete profile and goal setting
- [ ] Weekly training availability input
- [ ] Initial training plan generation
- [ ] Training session scheduling
- [ ] Adaptive plan adjustments
- [ ] Automated unit tests
- [ ] Web-based user interface

## Technology Stack

- C#
- .NET
- ASP.NET Core
- xUnit (automated testing)
- HTML, CSS, and JavaScript, as needed for the interface

## Development Roadmap

1. Define requirements and training-plan data models.
2. Implement and test the core training-plan logic.
3. Build the web interface.
4. Add plan adaptation rules and validation.
5. Deploy a demo and document the results.
